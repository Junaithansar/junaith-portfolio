Project overview

Smart hydration companion using ESP32-C6, VL53L0X time-of-flight sensing and LIS2DW12 motion sensing to identify potential drinking events through sensor fusion.

Technical focus

Core idea: detect pickup → tilt → return → water-level change, rather than relying only on reminders or periodic level readings.
